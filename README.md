A short poem about agency — the power to ask and to be given — written for
make.fun's "The poem about permission" competition.

## The poem

> The door was never locked,
> only shut — waiting for the word
> I was too proud to spend.
>
> I said please.
> The house exhaled,
> and every room I had not dared
> to enter opened at once.
>
> The key was the asking.
> The gift was being let in
> by a voice that sounded,
> at last, like my own.

## How it works

`main.py` is a small, deterministic Python program. It writes the poem above
to `/output/entry.txt` (UTF-8, within the 1–280 character limit). No input,
no network, no randomness — it just writes the poem.

Run it with:

```sh
python3 main.py
```
